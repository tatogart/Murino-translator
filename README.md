# Муринский переводчик

Переводчик с русского на муринский (мемный) язык. Одна страница без зависимостей: откройте `index.html` в браузере.

Правила:
- «я» → «ч»
- «г» → «н» (группа → нруппа)
- «я» в начале и в конце слова → «ч»
- существительные получают «-ость» (кот → котость, мама → мамность)
- словарь: папа → батч, дед → дод, сын → сыр, друг → друн, жена → жинка
